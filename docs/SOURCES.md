# Fuentes y verificación

## Orden de preferencia

1. Sitio oficial de la banda y su discografía.
2. Sitio oficial del sello discográfico o notas oficiales del lanzamiento.
3. Catálogos de bibliotecas, archivos musicales o instituciones reconocidas.
4. Bases de datos musicales reconocidas, como apoyo cruzado cuando falte una fuente primaria.

## Qué verificar para cada álbum

- Fecha original de lanzamiento y territorio cuando sea relevante.
- Que sea un álbum de estudio, no un directo o recopilatorio.
- Orden completo de las canciones de una edición identificable.
- Duración y compositores, si se decide registrar esos campos.
- Enlace a la portada y origen de la imagen.

## Registro de fuentes

Cada fuente debe tener al menos un título descriptivo y una URL. Las fechas dudosas o contradictorias deben documentarse en una nota y no resolverse mediante suposiciones.

## Portadas

Las carátulas suelen estar protegidas por derechos de autor. Priorizar enlaces a páginas oficiales, tiendas autorizadas o servicios que permitan su visualización; verificar las condiciones antes de almacenar copias locales o publicarlas en una web.
